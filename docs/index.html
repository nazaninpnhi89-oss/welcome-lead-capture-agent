What happens behind the scenes

  1. Message arrives

    Instagram DM, website form or messenger: wherever your customers are.

  2. Duplicate check

    Already welcomed? They won't get the same message twice.

  3. AI analysis

    Intent (buying / question / just browsing), name and topic of interest.

  4. Lead saved

    Everything goes into a database, ready for follow-up and reporting.

  5. Personal reply

    From a template you write, filled in with that customer's name and need.

  6. Sales alert

    Only for serious buyers, with a ready-made summary.

Built for real-world use

One welcome per customer

An email typed with different capitals, or a phone number written with or without spaces and dashes, still counts as one person. Saved first, sent second, so a dropped connection never causes a double message.

AI errors don't become wrong replies

If analysis fails for a message, that customer doesn't get a generic reply. They're retried on the next run instead.

Protected against abuse

Only requests carrying a valid Meta signature are accepted. Instructions someone types inside their message are never followed.

A full log of every run

Every message, decision and reply is recorded with a timestamp, so you always know what happened.
